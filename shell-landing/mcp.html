Install KillerMCP

KillerMCP includes all 81 KillerTools utilities plus tools from supported Killer apps in one local connection. The installer detects KillerShell and registers that shared connection with supported agent clients.

What it can do

KillerMCP exposes ten bounded, read-only KillerShell tools.

Search local filesMatch filenames, file contents, or both inside one folder tree.
List a directoryReturn files and folders directly inside one local directory.
Inspect an itemRead a file or folder's size, timestamps, type, and attributes.
Read textReturn a bounded portion of one local text file.
List processesReturn running process names, IDs, and memory use.
List servicesReturn Windows service names and current status.
Read event logsReturn recent Application, System, or Security log entries.
Inspect the registryReturn bounded subkeys and values from one registry key.
List drivesReturn drive type, readiness, capacity, and free space.
Hash a fileCalculate SHA-256 for one local file.

Data safety and permissions

Every KillerShell MCP tool is read-only. The integration cannot run terminal commands, start or stop processes, control services, change the registry, clear event logs, or create, edit, move, rename, or delete files.

Operations run locally through the installed KillerShell app. Results are returned to your MCP client and may be sent to its model provider. Depending on the request, results can include local paths, file text, process and service names, event messages, registry values, drive information, or file hashes. Review sensitive requests before approving them.

KillerShell uses the permissions of your Windows account. Protected files, registry keys, processes, services, and the Security event log may be unavailable unless the host already has permission to read them.

How it works

KillerMCP connects your AI assistant to supported Killer apps installed on your computer. You install it once, and it detects KillerShell automatically. For each request, KillerMCP validates the arguments and output limits, asks KillerShell to perform one specific read-only operation, validates the returned JSON, and then returns the bounded result to your assistant.

Current limits

  • Every file or folder path must be absolute. Registry paths must begin with a full HKEY name.
  • Search filename patterns are limited to 256 characters and content queries to 512 characters.
  • Searches, directory listings, processes, services, registry subkeys, and registry values return no more than 100 items through MCP.
  • Text reading returns no more than 32,768 characters. Registry values are limited to 4,000 displayed characters and event messages to 2,000.
  • Event log reads are limited to 100 recent entries from Application, System, or Security.
  • File hashing reads the complete selected file to calculate SHA-256 but does not upload or change it.
