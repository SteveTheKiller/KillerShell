Install KillerMCP

KillerMCP includes all 81 KillerTools utilities plus tools from supported Killer apps in one local connection. The installer detects KillerShell and registers that shared connection with supported agent clients.

Windows installer v0.1.0 coming soon
  1. Download and run KillerMCP Setup.
  2. Let setup connect your agent. It registers KillerMCP with Codex, Claude Code, Claude Desktop, Cursor, GitHub Copilot, Gemini CLI, and Windsurf when found. No source checkout, Node installation, or manual command list is required.
  3. Open a new agent chat and ask. Available tools are discovered automatically.

Optional hosted KillerTools connection

The hosted endpoint provides 64 browser based KillerTools utilities without an installation. It cannot search files on your computer.

What it can do

KillerMCP currently provides one bounded, read-only KillerShell search tool.

Search by filenameUse plain text or a wildcard pattern inside a chosen folder.
Search file contentsFind files containing a specific text value.
Combine both filtersRequire a matching filename and matching content in one request.
Bound the resultsReturn up to 100 matches without modifying any file.

Data safety and permissions

The search runs locally and reads only the absolute folder supplied in the tool call. It does not upload files to the Cloudflare Worker and cannot edit, move, or delete them.

Your MCP client and model provider can receive the search path, query, and returned metadata or snippets. Review the requested folder before approval and apply the provider's data handling rules to confidential paths and content.

How it works

KillerMCP is an open-source local runtime. It starts one MCP connection, detects installed Killer apps, and exposes only the adapters supported by those installed versions. For this page, it calls the KillerShell command line search and validates the bounded JSON response.

The optional public endpoint is a separate open-source MCP server running as a Cloudflare Worker. Requests sent to that URL are processed on Cloudflare. It offers web based KillerTools utilities and has no route to local files.

Current limits

The root path must be an absolute local directory. Filename patterns are limited to 256 characters, content searches to 512 characters, and results to 100 matches. The public installer is still being prepared and has not been released.
