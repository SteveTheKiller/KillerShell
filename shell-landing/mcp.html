KillerShell MCP

Find the file you need without leaving your agent.

What it does

KillerMCP gives your agent a bounded KillerShell file search. Search an absolute folder by filename, file contents, or both, and receive up to 100 matching results.

killer find files named invoice in C:\Clients

The search runs on your computer and reads only the folder you provide. It does not change files.

One connection for the family

KillerShell is part of KillerMCP, the shared connection for KillerTools and the Killer apps. You install KillerMCP once. It finds supported apps on your computer and makes their tools available to your agent.

The installer and KillerShell integration are still in development. Setup instructions and a download link will appear here when they are ready for release.
